Real Filters

An Android app that reveals the mathematics behind image filters. Every effect is just a matrix.

Download APK View on GitHub

Features

🖼️

Load Any Image

Supports JPEG, PNG, GIF, BMP, WebP, TIFF, HEIF, and SVG. Load from gallery or file browser.

🔢

See the Math

Every filter displays its underlying 4×5 color matrix or NxN convolution kernel in real-time.

✏️

Write Your Own

Edit matrix values directly. Create custom convolution kernels of any size. Experiment freely.

📚

Layer System

Stack multiple filters with adjustable opacity. Reorder, toggle, and compose effects.

✖️

Matrix Composition

Multiply matrices together mathematically. See how combining filters creates new effects.

💾

Export & Share

Save filters as JSON. Import filters from others. Build a library of custom effects.
